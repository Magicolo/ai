## Non-Obvious Facts (read before touching anything)

### 1. Host vs Container Boundary
- **opencode runs on host only, comfy MUST stay in container** via `serve.sh` (`docker compose run --build --rm --detach ...`). Never `comfy launch` on host; host has no comfy binaries by design (`pip uninstall comfy-cli/comfy-mcp`, `~/.config/comfy-cli` removed, project-local `.opencode/opencode.json` carries `mcp: { comfy-mcp: { type: remote, url: http://localhost:9000/mcp, oauth:false }}` — moved out of global `~/.config/opencode/opencode.json` 2026-09-10, so the server is scoped to this folder).
- `serve.sh` uses **`run` not `up`** intentionally — keep it that way. `run --service-ports` publishes 8188/7860/9000 under the fixed container name `comfy` (`--name comfy`, stable and resolvable on the compose network). `docker ps` shows `comfy Up (healthy)`. A second `serve.sh` while one runs fails fast on the name — same outcome as the old port-bind failure, clearer message.
- zoomy lifecycle is driven by `zoomy.sh`: it starts zoomy itself (`run --build --rm --detach --service-ports --no-deps`, ephemeral `comfy-zoomy-run-<hash>`, UI at `http://localhost:7861`). Standalone since 2026-09-16: the image carries the whole engine (diffusers/ACE/MMAudio/RIFE), models live in the `zoomy_models` volume, outputs land in `./Zoomy/output` — no comfy involvement, no `depends_on`, no `ZOOMY_COMFY_ADDRESS`. First launch ever needs the one-shot provisioner (command in `zoomy.sh`). ⚠️ 2026-09-24 disk cleanup: the `comfy_zoomy_models` volume (~65GB) was REMOVED and `Zoomy/output/` cleared — zoomy needs a full re-provision before any Render works. Never restart comfy or edit `serve.sh` for zoomy — `comfy` is an untouched backup.
- `COMFY_BIN` / `COMFYUI_URL` env passthrough is via `mcp-proxy` style `--pass-environment` (now inlined bridge). Don't set them manually.

### 2. Dockerfile Rebuild Safety
- Rebuilds are frequent (`--build` on every `serve.sh`). Workflows MUST survive rebuild.
- ALL requirements are baked from the **host checkout** at build time (2026-09-21 rewrite, fixes the `comfy-aimdo` crash): first line `# syntax=docker/dockerfile:1`, then `COPY --parents Comfy/requirements.txt Comfy/custom_nodes/*/requirements*.txt /opt/comfy-requirements/` + a `RUN` loop `pip install --no-cache-dir --requirement` per file over `/opt/comfy-requirements/...` AND `/comfy/custom_nodes/*/requirements*.txt` (the image-cloned QoL packs). The loop covers core + every custom node on the host; per-file install keeps pip resolution isolated.
- **Lesson (do not regress)**: the old pattern fetched `--requirement https://raw.githubusercontent.com/.../master/requirements.txt`; Docker cached that layer, upstream added `comfy-aimdo==0.5.5` (used by main.py/comfy/storage.py), and `serve.sh` died with `ModuleNotFoundError: No module named 'comfy_aimdo.storage'`. Host-path COPY means the layer hash tracks the local checkout, so a `--build` always picks up a moved ComfyUI commit. **Never re-introduce remote requirement URLs in the Dockerfile.**
- `COPY --parents` needs the `# syntax=docker/dockerfile:1` directive (stable frontend; `1.7` stable fails, `1.7-labs` works — `:1` is used) and is required because a plain wildcard `COPY */requirements.txt` silently collapses same-named files to one. No-match wildcards are silently ignored, so zero custom nodes is safe.
- The four QoL packs are still `git clone`d into `/comfy/custom_nodes/...` at build (fresh-clone fallback for the volume overlay); their requirements are installed by the loop, not by the clone RUN. Never add host-side `pip install` — installs belong in the image.

### 3. Entry.sh Dual-Process & Patches
- PID1 is `init` (docker `init: true` handles zombie reaping); entry.sh `wait -n` then kills the other pid for clean `docker stop`.
- Must run `comfy set-default /comfy` every boot because config at `/root/.config/comfy-cli/config.ini` is not volume-persisted.
- **Loopback fixed key patch**: upstream `nodes.py:_resolve_workflow_key` hashes workflow JSON, so `comfy run` (cli) vs UI Queue produce different workflow hashes → different cache dirs → history lost. We patch to return fixed `"ernie_zoom_fixed"` when `cache_path` is `/comfy/output/loopback_ernie_zoom` (or legacy `"ernie_zoom"`). Patch is idempotent and applied at runtime via `entry.sh` Python heredoc + at build via host file. If you clone loopback fresh, entry.sh re-patches.
- **Square edges**: entry.sh stamps `Comfy/user/default/comfy.settings.json` to `{"Comfy.LinkRenderMode":"Straight"}` (options: Hidden/Linear/Spline/Straight — Straight = square right angles). Also creates file if missing. Workflows carry `_linkRenderMode:Straight` in `extra` as documentation, but real setting is global.
- **Cache migration**: on boot, if `/comfy/temp/image_loopback/ernie_zoom_fixed` exists and new `/comfy/output/loopback_ernie_zoom/ernie_zoom_fixed` does not, `cp -a` migrates. Manual migration already done for current history (4 frames).
- **No runtime pip installs anymore** (2026-09-21): the old `for req in /comfy/custom_nodes/*/requirements.txt` boot loop is gone — dependencies are baked into the image (§2). Nodes added after a build are handled by ComfyUI-Manager at startup.

### 4. Loopback Confinement to `output/`
- Old `cache_path="ernie_zoom"` → `_cache_dir` returned `/comfy/temp/image_loopback/<workflow_key>/ernie_zoom` (relative path, trapped under `get_temp_directory()`). Escaping with `../../output` is blocked by `candidate.startswith(base_root)`.
- New `cache_path="/comfy/output/loopback_ernie_zoom"` → `_cache_dir` returns `/comfy/output/loopback_ernie_zoom/<workflow_key>` (absolute branch, `os.path.isabs`). With fixed key, final dir is `/comfy/output/loopback_ernie_zoom/ernie_zoom_fixed/` containing `history/`, `cached_img.png`, etc. **All generation is now under `Comfy/output/`** — cleanup is `rm -rf Comfy/output/*` (also clears history).
- Workflow widgets: `Image-Loopback-Load/Cache/Configure` all have `cache_path` widget 0 = new absolute path. Prettier formatting preserves this.

### 5. GPU & Model Notes
- Host reports `RTX 4060 Ti 16GB` (17175674880 bytes → 15.57 GiB usable) + secondary 2060. comfy-mcp `server_info` confirms same.

### 12. Unified Coding / Software-Development Standards (binding posture for all new work)
- **Scope + precedence**: this section states the unified posture; on any conflict, per-app §10 (zoomy) / §11 (voyage) plus that app's `pyproject.toml` / `scripts/*gates*.sh` win. Pins live in code (`pyproject.toml`, Dockerfiles), never restated here. Normative detail lives in `Zoomy/DESIGN.md` / `Voyage/DESIGN.md`; `AGENTS.md` holds pointers + non-obvious deltas only.
- **Simplicity-first (highest bias)**: KISS over clever; YAGNI / abstraction-on-demand — no speculative generality, no framework for one use; pragmatic DRY (tolerate ~3× duplication before abstracting; wrong abstraction costs more than duplication); pragmatic SOLID (SRP + DIP mainly, no dogma); low-boilerplate (prefer stdlib + existing seams over new layers); soft signals, not hard CI: ~500-line module split signal, god-module watch (`cli/supervisor`/video workers), dead-code removal on sight (unused adapters, alias-over-alias shims, served-out migrations).
- **Readability + naming + docs**: names are full words — no acronyms/abbreviations/contractions/single-letter variables (allow-list `lora/comfy/json/http`; node `class_type`s + input keys stay literal; prefer `autoencoder/text_encoder/base_model` over `vae/clip/unet` in our names); small reviewable units; comments explain *why*, never *what*; every module docstring states purpose + DESIGN § ref; Boy-Scout rule (leave the file cleaner); no magic numbers (named constants with *why*, e.g. VRAM-derived `local_attn_size=16`, `REPORTED_FRAMES_SLACK`, sync-frame floor 17).
- **Toolchain (both apps)**: py3.12, single-source `pyproject.toml`; `ruff ALL` (line-length 100) + `ruff format` + `mypy strict` + `warn_unused_ignores` + `pytest` (`-p no:cacheprovider --strict-markers`) — Voyage target is `ALL` to match Zoomy (upgrade pending gate cleanup; current Voyage select `E,F,I,UP,B,A,C4,DTZ,W` + `exclude=["issues/"]` + mypy `follow_imports=skip` for GPU stacks stays until the upgrade lands). Never `ruff format` `Voyage/issues/*.md` (evidence fences corrupt). All deps containerized — never `pip install` on host (host needs only `docker`); gate caches out of tree (`RUFF_CACHE_DIR/MYPY_CACHE_DIR/HYPOTHESIS_STORAGE_DIRECTORY=/tmp/...`, `PYTHONDONTWRITEBYTECODE=1`).
- **Tests (value-first, added alongside or after the implementation)**: no mandated failing-first — add tests where they pay for themselves (bug-fix reproductions, contract pins, risky paths), skip low-value coverage of trivial or already-covered behavior. Fake-backend-first on `tmp_path` throwaway runs with real media (ffmpeg `testsrc`/sine, no GPU/network/host paths); assert `DONE + manifest.json + validate_run==[]`. UI changes need draw-path coverage (construct + bind + headless render for every family/panel) plus launch smoke (HTTP 200); reproduce reported UI errors from server logs first. Verify every external API live in-container (introspect `EVENTS`/signatures; never trust stubs).
- **Property-based over arbitrary examples (required for pure cores)**: `seeds/paths/atomic/beats/metrics/config` and any deterministic core get Hypothesis properties (round-trip, idempotence, invariants) with domain-constrained generators; prefer `st.data()` over 6+-arg `@given`; fresh `TemporaryDirectory` per filesystem example (never share `tmp_path` across examples); suppress health checks only with documented reason; pin `nan/inf/singular/boundary` cases deterministically (generators hit them only probabilistically).
- **Modularization + boundaries (hard GPU ban)**: supervisor/CLI/config/atomic/persistence/paths never import `torch/transformers/diffusers` at module scope (grep gate; GPU only behind worker `handle_init` or lazy function imports with `find_spec` guards); `Protocol` seams between supervisor and backends; absolute paths on the wire, run-relative refs in store (`resolve_stored_path` + re-anchor, traversal-tested); single writer per run (`fcntl` lock, one commit = one hold); worker-reported counts/tapes clamped + validated before use.
- **Durability (atomic rule)**: all critical writes via `temp *.partial + write + flush + fsync + os.replace + fsync_dir`; ledger appends `flush+fsync`; `DONE` is a single atomic write (never `DONE.partial`); `state.json` advances only after artifacts + checksums + `DONE`; `validate_run` stays read-only (recomputes checksums, orphan-scans `*.partial/*.tmp*`, checks contiguity/frames/duration/tapes).
- **Subprocess / RPC / ffmpeg guards**: no shell; typed JSONL framing with response cap (8 MiB) + non-blocking reads with deadlines; per-worker restart budgets + circuit-breaker to FAILED + honest abort statuses (`FAILED` except `DiskSpaceError → PAUSED_DISK_FULL`); gauge/embed timeouts (5 s/60 s class); stdout redirected so upstream prints can't break framing; `ffmpeg` arg-lists (never strings), verify non-empty outputs at every assembly step; never `acrossfade` short-tail joins (manual fades/delays).
- **Errors + validation**: explicit exception taxonomy (`Recoverable` vs `Fatal`, branch on class never message); every worker op validates at the boundary (`checked_request`/`validate_*`, finite/range/shape checks) before model work; torn JSON wrapped fail-loud; no bare `except`, no silent swallows (intentional never-break-commit paths get targeted handling + tests, never blanket `noqa`).
- **Performance / VRAM discipline**: record VRAM peaks + per-stage timings for GPU changes (benchmark artifacts, not claims); serialize GPU access (`nvidia-smi` check; OOM under contention is inconclusive — re-run idle); evict/rebuild around audio swaps (`del` alone frees nothing); chunked VAE decode + CPU offload where measured; finalize stays chunked/streamed (never all-at-once past ~200 frames).
- **Gates + fix-on-sight + docs**: gates (`ruff check + format-check + mypy + pytest`) run in-container after each completed task — a task is done only when green; fast `run-tests.sh` for iteration; scripts held to `set -euo pipefail`, quoted `"$@"`, `bash -n` clean. Fix violations on sight (small obvious inline; large → `issues/` files with rank-ordered evidence, repro, fix candidates); reverify every finding vs live code, cite `file:line`, never memory. Delete obsolete tests WITH the code they cover — a test for removed behavior (deleted verb/module/flag, dead TUI) is deleted in the same change, never left failing or `importorskip`-skipped; trim dead cases from mixed files, rename files whose subject changed. Every behavior change updates `DESIGN.md` (+ `AGENTS.md` if non-obvious); never undo a concurrent agent's work (re-read region, minimal anchors, own scope only, per-commit approval per §9).

## Known Gotchas

- Changing `cache_path` to an absolute under `/comfy/output` is the ONLY way to confine loopback; relative paths are jailed under temp.
- Workflow `id` changes on save can drift hash key — fixed key patch prevents history loss.
- Frames are **1376×768** (official Ernie preset; ~20s/frame on 4060 Ti). Don't change resolution without re-checking VRAM + re-rendering the seed PNG at the new size (cold-start seed must match frame size). Line-art loop is **512×512** (~3.5s/frame; its seed must stay 512² too).
