# 036 — `strict` in name only: 223× `Any` + `cast` + untyped JSON boundaries

- Status: open
- Severity: medium-high (the JSON/RPC boundary — highest-risk surface — is
  untyped)
- Area: standards — typing discipline
- Rank rationale: `Any` count is the metric; load-bearing sites include the atomic
  JSON helpers, console, supervisor state, and worker payloads.

## Technical description

`rg -n "\bAny\b" Voyage/voyage | wc -l` → 223 (orchestrator-verified
per-file counts 2026-09-25: `video_causvid.py:36`, `video_ltxv.py:31`,
`video_longlive.py:30`, `supervisor.py:17`). Load-bearing examples:

- `voyage/atomic.py:47` `def atomic_write_json(destination: Path, payload: Any)`,
  `:51` `def read_json(path: Path) -> Any`
- `voyage/console.py:95` `self._rich: Any = None`
- `voyage/supervisor.py:544,584` `state: Any`, `voyage/director.py:179` `state: Any`,
  `voyage/media.py:62` `data: Any = json.loads(...)`,
  `voyage/cli.py:475` `state.status = status # type: ignore[assignment]`
- `voyage/workers/director.py:241,303` `cast("TransitionPhase", str(...))` —
  narrows `str` to Literal without validation
- `voyage/audio/acestep.py:36-37` `diffusion: Any; language: Any`,
  `voyage/workers/video_causvid.py:378-379,397,414,518,523,552,567,592,600,605,

No `disallow_any_*`; no `ANN` at all, so `*args: object, **kwargs: object` in
`fake_backends.py:115,124` passes silently. (Zoomy also lacks `disallow_any_*`
but carries far fewer `Any` per module plus a documented `ANN401` carve-out.)

## Why this is an issue

`strict` mode that permits 223 `Any`s is strict about the easy parts and permissive about the risky ones: the JSON/RPC boundary — the exact surface where malformed data enters — is untyped, so shape errors become runtime surprises in workers instead of checker errors at the boundary. A `cast` that narrows `str` to a Literal without validation actively asserts knowledge the code does not have. Without a ratchet the count only grows, and each new `Any` is a hole future refactors must navigate blind.

## Evidence

Per-file `rg -c Any` output above (orchestrator-verified); `rg -n "cast"
Voyage/voyage` → `workers/director.py:241,303` only.

## Reproduction

`rg -n "\bAny\b" Voyage/voyage | wc -l`; `rg -n "type: ignore|cast" Voyage/voyage`
(25 ignores per sweep).

## Resolution candidates

1. Type the JSON boundary once (`TypedDict`/`BaseModel` for RPC payloads;
   `JsonValue = dict[str,JsonValue]|...` for `read_json`).
2. Replace `cast` with `assert phase in get_args(TransitionPhase)`.
3. Track `Any` count downward (gates comment or ratchet test).
